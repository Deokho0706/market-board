# 에러 메시지 정책

## 원칙
- 사용자 노출 메시지: 한국어, 일반 문구, 내부 정보 없음
- 서버 로그: console.error로만, 스택/경로/키 포함 가능
- API 응답 body에 stack trace, 파일 경로, 환경변수명 포함 금지

## API 키 관리
- 모든 API 키는 서버 환경변수로만 관리
- .env.local에 저장, .gitignore에 포함됨
- NEXT_PUBLIC_ 접두사 변수로 클라이언트 노출 금지

## 에러 분류표
| 상황 | 사용자 메시지 | 서버 로그 |
|------|-------------|---------|
| FRED API 실패 | "시장 지표를 불러올 수 없습니다" | 상세 에러 전체 |
| Yahoo 실패 | "시세 데이터를 불러올 수 없습니다" | 상세 에러 전체 |
| Polymarket 실패 | "확률 데이터를 불러올 수 없습니다" | 상세 에러 전체 |
| 환경변수 누락 | "서비스 설정을 확인 중입니다" | 변수명만 |
