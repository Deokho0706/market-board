\[작업 원칙]

* 불필요한 파일 삭제 전 반드시 안전성 검증 수행
* 레거시 코드 제거는 단계적으로 진행
* 한 번에 여러 리팩토링 수행 금지

\[검증 원칙]

* 모든 변경 후 최소 검증 수행:

  * npm run dev
  * npm run build
* 실패 시 수정하지 말고 원인 먼저 보고

\[구조 원칙]

* Vite 구조 기준 유지 (root: src)
* public 폴더는 정적 리소스만 사용
* 런타임 fetch 데이터는 public 경로 사용

\[성능 원칙]

* MCP는 필요한 경우만 사용
* 에이전트 동시 호출 최소화
* 긴 출력 대신 요약 우선

\[안전 원칙]

* 자동 삭제/수정 금지 (사용자 승인 필수)
* 한 번에 하나의 작업만 수행
